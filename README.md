## 🧑‍🏫 Teaching Philosophy

I believe students learn programming best when they understand not only **how to write code**, but also:

* why the program works
* how data flows through the program
* how to break a problem into smaller steps
* how to design a solution before coding
* how to test and improve their program
* how programming concepts can be applied to real-world problems

My teaching approach emphasizes:

> **Understand → Practice → Experiment → Analyze → Apply**
